# SOSTOTRUS3DS

Инструменты для русского перевода **Story of Seasons: Trio of Towns** (Nintendo 3DS, американская версия).

В репозитории лежат только инструменты и, со временем, перевод. Файлов игры здесь нет и быть не должно: папки `rom/`, `text/` и `out/` исключены через `.gitignore`.

## Где в игре текст

| Что | Файл в RomFS | Объём |
|---|---|---|
| Диалоги, письма, системные сообщения | `Msg.xbb` | 797 файлов, 74 827 строк, около 8,8 млн знаков |
| Названия предметов, имена, пункты меню | `DataText.xbb` | 81 таблица, 5 933 строки |
| Шрифты | `Font/mainfont.bffnt`, `Font/subfont.bffnt` | кириллица (А–я, Ё, ё) уже есть |
| Надписи в картинках | `Layout/*.arc` | этим инструментом не обрабатываются |

Уникальных строк в `Msg.xbb` меньше, чем всего: 32 806, около 5,3 млн знаков. Повторы заполняются автоматически командой `fill`.

Текст хранится в UTF-16, поэтому русские буквы записываются напрямую, без таблиц замены.

## Что нужно

- Python 3.8 или новее. Дополнительные библиотеки не нужны.
- Распакованный RomFS своей копии игры.

## Порядок работы

Все команды выполняются из корня репозитория.

### 1. Положить файлы игры

Скопируйте из распакованного RomFS в папку `rom/`:

```
rom/Msg.xbb
rom/DataText.xbb
rom/mainfont.bffnt
```

### 2. Проверить, что версия подходит

```bash
python tools/sosxbb.py verify rom/Msg.xbb
```

```bash
python tools/sosxbb.py verify rom/DataText.xbb
```

Обе команды должны ответить `OK: rebuilt archive is byte-identical to the original`. Если ответ другой, файл от другой версии игры, и продолжать нельзя.

### 3. Извлечь текст

```bash
python tools/sosxbb.py unpack rom/Msg.xbb text/Msg
```

```bash
python tools/sosxbb.py unpack rom/DataText.xbb text/DataText
```

Получится по одному JSON-файлу на каждый файл игры. Повторный запуск уже введённые переводы не стирает.

### 4. Переводить

Каждая запись выглядит так:

```json
{
 "n": 1,
 "f": 2,
 "id": "MES_EV_ANIMAL_DEATH_OLD_01",
 "en": "(<MOJI0>... You did a great job all\nthis time.)",
 "ru": ""
}
```

Перевод вписывается в поле `ru`. Остальные поля менять нельзя: по ним строка находится в игре. Пустое `ru` означает, что в игре останется английский текст.

Правила:

- Всё в угловых скобках — управляющие теги: `<PAGE>`, `<_____MYNAME_____>`, `<MOJI0>`, `<BLUE>…</BLUE>`, `<FACE_…>`, `<POS_RIGHT>`. Их нужно переносить в перевод без изменений.
- `\n` — перенос строки, `<PAGE>` — новая страница диалога. Строки переносятся вручную.
- Если в оригинале стоит `\r\n`, в переводе на том же месте тоже должно быть `\r\n`.
- В диалогах строка должна быть не шире 280 пикселей, на странице не больше трёх строк. Считать вручную не нужно, это делает команда `check`.

### 5. Размножить повторы

```bash
python tools/sosxbb.py fill text/Msg
```

Команда копирует перевод во все записи с точно таким же английским текстом.

### 6. Проверить

```bash
python tools/sosxbb.py check text/Msg --font rom/mainfont.bffnt
```

Команда сообщает о потерянных тегах, о буквах, которых нет в шрифте, о слишком широких строках и о лишних строках на странице.

Посмотреть, сколько переведено:

```bash
python tools/sosxbb.py stats text/Msg
```

### 7. Собрать

```bash
python tools/sosxbb.py pack rom/Msg.xbb text/Msg out/Msg.xbb
```

```bash
python tools/sosxbb.py pack rom/DataText.xbb text/DataText out/DataText.xbb
```

### 8. Запустить в игре

Через LayeredFS в Luma3DS: положите собранные файлы в `luma/titles/<TitleID игры>/romfs/` на карте памяти и включите в настройках Luma пункт `Enable game patching`. Образ игры пересобирать не нужно. В эмуляторе Azahar (бывший Citra) те же файлы кладутся в папку модов игры.

## Перевод в репозитории

Готовый перевод хранится в папке `translation/` без английского текста: только номер строки, её метка, контрольная сумма оригинала и русский текст.

Подставить его в свои распакованные файлы:

```bash
python tools/sosxbb.py load translation/DataText text/DataText
```

Сохранить свои правки обратно в `translation/`:

```bash
python tools/sosxbb.py save text/DataText translation/DataText
```

Для `Msg` команды те же, с `translation/Msg` и `text/Msg`.

## Что проверено, а что нет

Проверено на файлах американской версии:

- оба архива пересобираются без изменений байт в байт;
- после вставки русского текста архив собирается, читается обратно, и все остальные строки остаются прежними;
- переведённый файл может быть длиннее оригинала, смещения пересчитываются.

Не проверено: запуск собранных файлов на консоли или в эмуляторе. Первым делом стоит перевести пару строк, собрать и убедиться, что игра их показывает.

## Формат файлов

Описание структур `XBB` и `PAPA` находится в начале файла `tools/sosxbb.py`.
