# SOSTOTRUS3DS

Инструменты для русского перевода **Story of Seasons: Trio of Towns** (Nintendo 3DS, американская версия).

В репозитории лежат только инструменты и, со временем, перевод. Файлов игры здесь нет и быть не должно: папки `rom/`, `text/` и `out/` исключены через `.gitignore`.

## Где в игре текст

| Что | Файл в RomFS | Объём |
|---|---|---|
| Диалоги, письма, системные сообщения | `Msg.xbb` | 797 файлов, 74 827 строк, около 8,8 млн знаков |
| Названия предметов, имена, пункты меню | `DataText.xbb` | 81 таблица, 5 933 строки |
| Шрифты | `Font/mainfont.bffnt`, `Font/subfont.bffnt` | кириллица (А–я, Ё, ё) уже есть |
| Надписи в картинках | `Layout/*.arc` | этим инструментом не обрабатываются |

Уникальных строк в `Msg.xbb` меньше, чем всего: 32 806, около 5,3 млн знаков. Повторы заполняются автоматически командой `fill`.

Текст хранится в UTF-16, поэтому русские буквы записываются напрямую, без таблиц замены.

## Что нужно

- Python 3.8 или новее. Дополнительные библиотеки не нужны.
- Распакованный RomFS своей копии игры.

## Порядок работы

Все команды выполняются из корня репозитория.

### 1. Положить файлы игры

Скопируйте из распакованного RomFS в папку `rom/`:

```
rom/Msg.xbb
rom/DataText.xbb
rom/mainfont.bffnt
```

### 2. Проверить, что версия подходит

```bash
python tools/sosxbb.py verify rom/Msg.xbb
```

```bash
python tools/sosxbb.py verify rom/DataText.xbb
```

Обе команды должны ответить `OK: rebuilt archive is byte-identical to the original`. Если ответ другой, файл от другой версии игры, и продолжать нельзя.

### 3. Извлечь текст

```bash
python tools/sosxbb.py unpack rom/Msg.xbb text/Msg
```

```bash
python tools/sosxbb.py unpack rom/DataText.xbb text/DataText
```

Получится по одному JSON-файлу на каждый файл игры. Повторный запуск уже введённые переводы не стирает.

### 4. Переводить

Каждая запись выглядит так:

```json
{
 "n": 1,
 "f": 2,
 "id": "MES_EV_ANIMAL_DEATH_OLD_01",
 "en": "(<MOJI0>... You did a great job all\nthis time.)",
 "ru": ""
}
```

Перевод вписывается в поле `ru`. Остальные поля менять нельзя: по ним строка находится в игре. Пустое `ru` означает, что в игре останется английский текст.

Правила:

- Всё в угловых скобках — управляющие теги: `<PAGE>`, `<_____MYNAME_____>`, `<MOJI0>`, `<BLUE>…</BLUE>`, `<FACE_…>`, `<POS_RIGHT>`. Их нужно переносить в перевод без изменений.
- `\n` — перенос строки, `<PAGE>` — новая страница диалога. Строки переносятся вручную.
- Если в оригинале стоит `\r\n`, в переводе на том же месте тоже должно быть `\r\n`.
- В диалогах строка должна быть не шире 280 пикселей, на странице не больше трёх строк. Считать вручную не нужно, это делает команда `check`.

### 5. Размножить повторы

```bash
python tools/sosxbb.py fill text/Msg
```

Команда копирует перевод во все записи с точно таким же английским текстом.

### 6. Проверить

```bash
python tools/sosxbb.py check text/Msg --font rom/mainfont.bffnt
```

Команда сообщает о потерянных тегах, о буквах, которых нет в шрифте, о слишком широких строках и о лишних строках на странице.

Посмотреть, сколько переведено:

```bash
python tools/sosxbb.py stats text/Msg
```

### 7. Собрать

```bash
python tools/sosxbb.py pack rom/Msg.xbb text/Msg out/Msg.xbb
```

```bash
python tools/sosxbb.py pack rom/DataText.xbb text/DataText out/DataText.xbb
```

### 8. Запустить в игре

Через LayeredFS в Luma3DS: положите собранные файлы в `luma/titles/<TitleID игры>/romfs/` на карте памяти и включите в настройках Luma пункт `Enable game patching`. Образ игры пересобирать не нужно. В эмуляторе Azahar (бывший Citra) те же файлы кладутся в папку модов игры.

## Перевод в таблице (Excel, LibreOffice, Google Таблицы)

Если удобнее переводить в таблице, `sostable.py` выгружает тексты в файл с колонками «Оригинал» и «Перевод» и загружает готовые переводы обратно. Для `.xlsx` нужен пакет `openpyxl` (`pip install openpyxl`); без него можно использовать `.csv` (разделитель «;», кодировка UTF-8).

Выгрузить все тексты (вместе с уже готовым переводом из `translation/`, если сначала выполнить `load`):

```bash
python tools/sostable.py export text/Msg perevod.xlsx
```

Только непереведённые строки или только нужные файлы:

```bash
python tools/sostable.py export text/Msg perevod.xlsx --untranslated --files "Talk_*" "Letter*"
```

В таблице:

| Столбец | Что это |
|---|---|
| Файл, №, Поле, ID | где строка стоит в игре; не менять |
| Служебное | коды портрета и говорящего перед репликой; не переводятся и подставляются сами |
| Оригинал | английский текст; не менять |
| **Перевод** | сюда пишется перевод (жёлтая колонка) |
| Заметки | для себя, при загрузке не читается |

Правила для колонки «Перевод»:

- все теги в угловых скобках переносятся без изменений: `<PAGE>` — новая страница, `<_____MYNAME_____>` — имя игрока, `<BLUE>…</BLUE>` — цвет, `<MOJI0>` — подставляемое число или слово;
- перенос строки внутри ячейки (Alt+Enter в Excel, Ctrl+Enter в Google Таблицах) — перенос строки в игре; в окне диалога не больше трёх строк на странице;
- пустая ячейка значит «ещё не переведено» и ничего не меняет;
- `{U+0001}` и подобное — невидимые служебные символы оригинала, их нужно оставить на месте.

Загрузить переводы обратно, с проверкой по шрифту игры:

```bash
python tools/sostable.py import perevod.xlsx text/Msg --font rom/mainfont.bffnt
```

Строки, где теги не совпадают с оригиналом, не принимаются; про слишком длинные строки и лишние строки на странице выводятся замечания с номером строки таблицы. С `--dry-run` таблица только проверяется, файлы не меняются. Дальше — обычные `fill`, `check`, `pack`.

Тексты `DataText` (названия предметов, имена, меню) выгружаются так же: `export text/DataText …`.

## Шрифт

В шрифте игры кириллица есть, но тонкая и широкая, а латиница жирная и узкая. Команда `restyle` перерисовывает русские буквы из обычного TTF-шрифта под размер латиницы. Нужна библиотека Pillow (`pip install pillow`).

```bash
python tools/sosfont.py restyle rom/mainfont.bffnt PT_Sans-Narrow-Web-Bold.ttf out/mainfont.bffnt --gain 1.25
```

Используется PT Sans Narrow Bold (ParaType, лицензия SIL OFL), файл есть в репозитории `google/fonts` в папке `ofl/ptsansnarrow`. Результат кладётся в `romfs/Font/` под двумя именами: `mainfont.bffnt` и `subfont.bffnt` (в игре эти файлы одинаковые).

Посмотреть, как строка будет выглядеть в игре:

```bash
python tools/sosfont.py preview out/mainfont.bffnt "Привет, ферма!" preview.png
```

Команде `check` из `sosxbb.py` стоит передавать уже новый шрифт: ширина русских букв в нём другая.

## Картинки интерфейса

Подсказки кнопок, заголовки окон, времена года и многие подписи меню — это не текст, а картинки внутри архивов `Layout/*.arc`. Нужна библиотека Pillow (`pip install pillow`).

Достать все картинки игры сразу (около 3300 PNG, папки повторяют архивы):

```bash
python tools/sosimages.py extract rom/Layout gfx
```

Собрать обзорные листы, чтобы быстро найти картинки с надписями:

```bash
python tools/sosimages.py sheets gfx gfx_sheets
```

После правки PNG в любом редакторе собрать только изменённые архивы:

```bash
python tools/sosimages.py pack rom/Layout gfx out/Layout
```

В `out/Layout` попадают только архивы, в которых что-то поменялось; их кладут в `romfs/Layout` патча. Картинка должна остаться того же размера, иначе `pack` сообщит об ошибке и пропустит её.

То же для одного архива:

```bash
python tools/sosgfx.py extract rom/Layout/ListGuideButton.arc gfx/ListGuideButton
```

```bash
python tools/sosgfx.py pack rom/Layout/ListGuideButton.arc gfx/ListGuideButton out/Layout/ListGuideButton.arc
```

Отредактированная картинка должна остаться того же размера.

Многие картинки хранятся в сжатых форматах ETC1 и ETC1A4. Они извлекаются так же, как остальные. При вставке заново сжимаются только те блоки 4×4 пикселя, которые действительно изменились, так что нетронутые части сохраняют исходные байты. Сжатие идёт с потерями: перерисованные места получаются чуть мягче, чем в PNG, как и у оригинальных картинок игры.

Простые надписи можно перерисовать автоматически. Таблица «картинка — слово» лежит в `translation/gfx/labels.json`, шрифт для надписей — Russo One (лицензия SIL OFL, папка `ofl/russoone` в репозитории `google/fonts`):

```bash
python tools/soslabels.py translation/gfx/labels.json ListGuideButton.arc gfx/ListGuideButton RussoOne-Regular.ttf
```

Команда стирает английское слово, сохраняет значок кнопки и рисует русское слово с контуром того же цвета. После неё выполняется `pack`.

Если слово стоит внутри большой картинки (например, “Qual” на панели качества), у записи указывается `"box": [x0, y0, x1, y1]` ― прямоугольник старого слова. Он закрашивается цветом фона из его левого верхнего угла, а новое слово рисуется без контура цветом `fill`.

## Подписи в разметке экранов

Некоторые слова (“Weight”, “Year”, “Hours” и другие) записаны прямо в файлах разметки экранов. Их меняет `soslayout.py` по таблице `translation/gfx/layout_text.json`:

```bash
python tools/soslayout.py translation/gfx/layout_text.json rom/Layout out/Layout
```

Под каждое слово в файле отведено место фиксированной длины; если перевод не влезает, инструмент сообщит, сколько букв допустимо.

## Перевод в репозитории

Готовый перевод хранится в папке `translation/` без английского текста: только номер строки, её метка, контрольная сумма оригинала и русский текст.

Подставить его в свои распакованные файлы:

```bash
python tools/sosxbb.py load translation/DataText text/DataText
```

Сохранить свои правки обратно в `translation/`:

```bash
python tools/sosxbb.py save text/DataText translation/DataText
```

Для `Msg` команды те же, с `translation/Msg` и `text/Msg`.

## Что проверено, а что нет

Проверено на файлах американской версии:

- оба архива пересобираются без изменений байт в байт;
- после вставки русского текста архив собирается, читается обратно, и все остальные строки остаются прежними;
- переведённый файл может быть длиннее оригинала, смещения пересчитываются.

Не проверено: запуск собранных файлов на консоли или в эмуляторе. Первым делом стоит перевести пару строк, собрать и убедиться, что игра их показывает.

## Формат файлов

Описание структур `XBB` и `PAPA` находится в начале файла `tools/sosxbb.py`.
